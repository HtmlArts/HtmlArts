A note about this place

Welcome to HtmlArts.

HtmlArts is a local-first library for reading, creating and collecting self-contained HTML books. It brings books, visual page styles and a quiet writing space into one thoughtful interface.

Local by natureDesigned to work from your own files and browser.
Open formatBooks remain portable HTML documents.
Reader firstSimple navigation and a distraction-light surface.
Made to growCreation, annotation and library tools arrive in stages.
